# Portfólio Profissional — Artur Fagundes

Esta é uma versão estática e responsiva do portfólio.

## Arquivos
- `index.html`: site completo.
- `curriculo-artur-fagundes.pdf`: coloque seu currículo com este nome na mesma pasta do `index.html`.
- Depois, se desejar, podem ser adicionados certificados e imagens de projetos em subpastas.

## Antes de publicar
Abra o `index.html` em um editor de texto e substitua:
- `SEU_EMAIL_AQUI`
- `SEU_LINKEDIN_AQUI`
- `SEU_WHATSAPP_AQUI`

Exemplo do WhatsApp:
`https://wa.me/55DDDNUMERO`

## Publicar gratuitamente no GitHub Pages
1. Crie uma conta no GitHub, caso ainda não tenha.
2. Crie um repositório chamado `arturfagundes.github.io`.
3. Envie o arquivo `index.html` e os demais arquivos do portfólio.
4. O endereço ficará, em geral, `https://arturfagundes.github.io`.
5. Depois você pode conectar um domínio próprio sem reconstruir o site.
